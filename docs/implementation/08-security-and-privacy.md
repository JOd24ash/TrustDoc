- Use only data the team is authorized to process and use for training.
- Prefer fictional, generated, or de-identified data for development and demos.
- Minimize personal data and restrict each officer to permitted cases.
- Encrypt uploads and stored records; define retention and deletion periods.
- Validate file content, size, and structure; scan uploads before processing. Do not trust file extensions alone.
- Keep an audit trail for access, rule changes, checks, and officer decisions.
- Avoid exposing personal data in browser code, logs, analytics, or model prompts unnecessarily.
- Secure extension/backend communication and keep credentials out of extension source.
- Obtain portal-owner authorization and security/privacy approval before any live government-portal integration.
- Do not bypass CAPTCHA, access controls, or portal workflows; do not submit decisions automatically.
