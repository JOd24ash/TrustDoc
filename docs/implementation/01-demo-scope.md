# 01 - SIH demo scope

## Goal

Demonstrate one complete officer review for one scholarship using a browser extension, a mock scholarship portal page, and fictional data. The plugin, not a separate application platform, is the product. Prove the plugin workflow before attempting broad scheme coverage or real portal integration.

## Demo sequence

1. Open the plugin's rule setup view and upload a sample scholarship notice.
2. Review extracted draft requirements and source page references.
3. Approve a rule-set version.
4. Open a fictional application in the mock portal and run checks from the extension side panel.
5. Show a passing check, a fixable issue, and an uncertain document signal.
6. Provide an applicant-facing correction reason or record the officer's final mock decision.

## Out of scope for the first demo

- Live MahaDBT data or production portal access.
- A separate full application management portal.
- Automatic approval or rejection based on AI.
- Claims that a model alone can prove a document is genuine or forged.
- General support for every scholarship and regulation.

Use fictional names and generated or authorized sample documents. Label simulated behavior clearly in the interface.
